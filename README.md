## Install

After you sign up you get a license key (on screen, in your welcome email and on
every receipt) and the download.

1. Unzip the file you downloaded
2. Go to `chrome://extensions`
3. Turn on **Developer mode** (top right)
4. Click **Load unpacked** and choose the unzipped folder
5. Click the extension's icon in your toolbar and paste your license key

Works on Chrome, Edge, Brave and Opera on a desktop or laptop. The browser needs
to be open with the extension running to claim, and it doesn't work on phones.
